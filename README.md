# 📊 Mean-Variance-Standard Deviation Calculator

This is the boilerplate for the Mean-Variance-Standard Deviation Calculator project. It is part of the FreeCodeCamp Data Analysis with Python curriculum.

## ✨ Overview

This project helps you calculate:

- 📈 Mean
- 📉 Variance
- 📏 Standard deviation
- 🧮 A matrix of values derived from a list of numbers

The goal is to build a function that takes a list of numbers and returns the statistical values in a clean and structured format.

## 🚀 Getting Started

1. Clone the repository
2. Open the project folder
3. Run the Python script

```bash
python main.py
```

## 🧪 Example

```python
# Example input
numbers = [1, 2, 3, 4, 5, 6]

# Example output
# mean = 3.5
# variance = 2.9166666666666665
# standard deviation = 1.707825127659933
```
